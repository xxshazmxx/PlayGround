# Rustfall — browser survival (PC + mobile)

A **Rust-inspired 3D survival game** that runs in the browser on desktop and mobile — no install, no server. Single-player prototype with AI scavengers. Built with **Three.js + Vite**. Add it to your phone's home screen to play it like an app (PWA manifest included).

## Play
- Spawn on a procedural island, chop 🌲 trees, mine 🪨 rocks, loot 🛢 barrels and 📦 crates at the central gas station.
- Craft 🪓 hatchet → ⛏️ pickaxe → 🔫 rifle, cook nothing (eat meat raw like a survivor), build 🧱 walls, fight 6 scavenger bots + wild boars/deer.
- Survive hunger, radiation at the monument, and bullets. Progress saves in `localStorage`.

## Controls
- **PC:** WASD + mouse (click to lock) • LMB hit/shoot • E gather • F eat • 1–6 weapons • Tab bag • B build • R rotate • Space/Shift jump/sprint
- **Mobile:** left stick to move • drag right side to look • FIRE / HIT / JUMP / EAT / BUILD buttons

## Dev
- `npm install`, `npm run dev` (port 3002), `npm run build` → `dist/`
- Verified headless: world boots (6 bots, 200+ nodes), melee harvest (+wood), rifle hit (38 dmg), wall place (−50 wood), crafting, responsive + touch HUD.
